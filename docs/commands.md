# Commands & Keybinds

## Commands

All commands need permission level 2 (operator or cheats enabled).

| Command | Description |
|---|---|
| `/titanores hearts get [player]` | Shows how many Titanium Hearts a player has eaten |
| `/titanores hearts reset [players]` | Removes all Titanium Heart bonus health |
| `/titanores hearts set <0-255> [players]` | Sets the exact number of Titanium Hearts eaten (each one = +2 hearts) |

## Keybinds & controls

| Input | Action |
|---|---|
| **N** (configurable in *Options › Controls › Titan Ores*) | Toggles Night Vision while wearing the Titanium Star helmet |
| **Shift + right-click** with a Titanium pickaxe, shovel or hoe | Toggles Area Mode (3×3) |
| **Sneak** while breaking a log with the Titanium axe | Breaks a single log instead of the whole tree |
| **Right-click in the air** with the Solarite Magnet | Turns the magnet on or off |
