# Titan Factory

![](assets/icons/titan_factory.png){ .mc-inline } `titanores:titan_factory`

!!! warning "Work in progress"
    The machine can already be placed and opened, but **energy** and **recipes** are not implemented yet.
    It is only available in creative for now.

## Current state

- Faces the player when placed and opens its interface with right-click.
- **6 input slots** (3 on each side) and **1 output slot** in the middle. Players cannot put items in the output.
- Items are kept when the world is saved and drop when the machine is broken (stone pickaxe or better).
- Hoppers and item pipes from other mods can insert and extract items.

## Planned

- Energy input (Forge Energy / RF, compatible with generators from other mods). The black bar on the right side of
  the interface is reserved for it.
- Machine recipes (up to 6 inputs → 1 output), probably including the production of [Emberium](emberium.md).
